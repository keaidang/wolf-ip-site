# 小程序壳 · 南通苏超小狼（AR 主轨）

本目录记录微信小程序 AR 模块的接入方式。小程序是 AR 体验的**主轨**，网页版（站点 `ar.html` + Three.js/WebXR）是兜底轨，两轨共用同一套积分规则。

## 能力边界

| 能力 | 小程序 AR | 网页兜底 |
| --- | --- | --- |
| 平面识别放置 | ✅ 相机帧 + 陀螺仪 | ✅ WebXR（部分机型） |
| 模型交互 | ✅ 双指缩放/旋转 | ⚠️ 简化版 |
| 动作播放 | ✅ 小狼庆祝动作 | ❌ 静态放置 |
| 合影分享 | ✅ 保存相册/分享好友 | ⚠️ 截图分享 |
| 零门槛 | ❌ 需微信环境 | ✅ 打开即用 |

## 目录约定（正式版）

```
miniprogram/

│   └── components/

├── utils/
│   └── api.js            # 对接后端 /api/me、/api/ar 等

```

## 接入要点

1. **模型规范**：glTF/GLB 单文件，贴图合图，总面数控制在 8K 以内保证中低端机流畅；庆祝动作一个循环动画即可。
2. **AR 框架**：使用小程序原生 AR 能力（`ar` 会话 + 平面检测），不引入第三方重 SDK。
3. **积分打通**：放置成功后调 `POST /api/ar`（带微信登录态），每日 +20 积分，与网页版同一接口同一上限。
4. **降级路径**：检测到不支持 AR 的机型时，页面内给出"打开网页版"入口（跳转站点 `ar.html`）。
5. **分享**：合影图支持保存相册与分享好友，分享行为与站点分享任务同权（+5 积分/日）。

毕业设计演示期内，网页版 `ar.html` 已完成"扫描动画 + 一键放置 + 积分入账"的简化闭环；小程序壳按上表规范预留，正式版开发时按本文件目录约定落地。
