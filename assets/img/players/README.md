## 照片要求

- 竖版 3:4 最佳（如 900×1200），人物居中，页内自动 `object-fit: cover` 裁切展示
- 格式 `.jpg`；如手里是 PNG/HEIC，先用下面的脚本一键转正

## 一键处理（推荐）

1. 原始照片（任意文件名，能认出是谁即可）放入 `assets/img/players-raw/`
2. 运行：`python docs/prepare-player-photos.py`
3. 脚本按「文件名含中文姓名 / 拼音 / 号码」自动匹配，居中裁切 3:4、限宽 900、转 JPEG 后落入本目录
